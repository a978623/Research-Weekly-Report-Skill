# 周报骨架

下面说明结构，不是可直接提交的成稿。标题、时态和篇幅随用户最新要求调整。

## 一、本周工作总结

开头用一两句交代本周实际围绕的问题。

核心论文分别成段：完整题名、相关方法、自己的理解、对课题的价值及必要条件。对用户重点强调的机制和研究思考多写，辅助阅读少写。

代码、数据和实验只补充实际完成范围。有新的综合认识时，用短段串起论文与研究问题；没有就不强行收束。

## 二、下周工作安排

开头说明准备延续的问题。

逐篇列出已确认要读的论文，使用完整题名，写清重点、比较对象或希望回答的问题。用户指定名单时保留原名单，不以模板数量替换或增加论文。

安排也可以包含实际可做的数据核实、代码检查或实验，但不要把建议直接写成用户已经决定执行的事项。
